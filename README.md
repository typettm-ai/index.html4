# CarQR 🚗

CarQRは、車検証・抹消車検証・予備検査証のQRコードを読み取り、
自動車税・重量税の計算を支援するWebアプリです。

## 現在の開発状況

### 現在の進捗

- ✅ 画像読込
- ✅ Canvas描画
- ✅ グレースケール
- ✅ 二値化
- ⏳ QRコード読取を実装予定

## 開発目標

- 車検証QRコード読取
- 複数QRコード対応
- 車両情報解析
- 自動車税計算
- 重量税計算
- CSV出力
- スマホ対応

## 開発環境

- HTML
- CSS
- JavaScript
- ZXing
- OpenCV.js（導入予定）
